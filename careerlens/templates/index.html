How it works

  1. Ingest & chunk — the resume and project READMEs are split into overlapping chunks.
  2. Embed — chunks are embedded locally (sentence-transformers when available, otherwise a built-in TF-IDF embedder).
  3. Retrieve — the job description is embedded the same way and the top-k chunks are fetched by cosine similarity.
  4. Compose — a grounded analysis is built from the retrieved chunks, with citations. With an LLM key set (CAREERLENS_LLM_PROVIDER + OPENAI_API_KEY / GROQ_API_KEY / GEMINI_API_KEY) a hosted LLM writes the narrative; without one, an extractive composer does the job.

Honesty rule: a skill in the JD with no supporting evidence is listed as a gap — never claimed.
