# Delhi Air Quality and Health Dashboard

A data dashboard built with Python, Flask, Pandas, MS Excel, Power BI
and Tableau, using real air-quality data from Open-Meteo and CAMS for
June to November 2026. It covers three Delhi areas across 489
station-days and found RK Puram had the worst average AQI at 232.

The Flask app serves the dashboard, Pandas handles the data cleaning
and aggregation, and the analysis is exported to Excel. A Tableau
workbook and a Power BI guide accompany the dashboard so the same
analysis can be explored in business-intelligence tools.
