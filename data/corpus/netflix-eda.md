# Netflix Dataset Exploratory Data Analysis

An exploratory data analysis of more than 8,800 Netflix catalogue
records, written in Python with Pandas and Matplotlib. The work
cleaned the raw data and analysed content type, genre, rating,
country and release-year fields to surface catalogue trends through
charts and visualisations.

The analysis used Pandas for data cleaning, grouping and aggregation,
and Matplotlib for plotting distributions and comparisons across
genres, countries and years.
